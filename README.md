# CS300

#### Question 1: What was the problem you were solving in the projects for this course?

<p>The problem I was solving with this project was a console app that prints out course information given from a csv file.</p>

#### Question 2: How did you approach the problem? Consider why data structures are important to understand.

<p>I approached the problem by determining which data types out of the 3 we worked with 
(vector, hashtable, tree) would be more efficient for the console app. Ultimately, based upon my algorithm and run-time analysis, 
I came to the conclusion that a binary search tree would be more beneficial for the program in terms of speed and ease of use.</p>

#### Question 3: How did you overcome any roadblocks you encountered while going through the activities or project?

<p>During this project, the biggest roadblock was visualization of data structures. The way I overcame this issue was by drawing what was happening (or supposed to be happening) at each step of the code. </p>

#### Question 4: How has your work on this project expanded your approach to designing software and developing programs?

<p>My work on this project has expanded my approach to designing software and developing program by allowing me to understand how to determine which data structure is most useful in different situations.</p>

#### Question 5: How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

<p>My work on this project evolved the way I write programs that are maintainable, readable, and adaptable by designing the code in a way where any csv file in the same format as the initial will be able to be
red and sorted, making it easily scalable or applicable to other projects. It would also be relatively simple to rework the code to fit any type of csv file by adjusting print names of items and formatting. </p>
